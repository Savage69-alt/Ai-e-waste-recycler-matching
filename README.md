🌸 SkillSwap for Women

Empowering Women Through Skill Sharing and Collaborative Learning

SkillSwap is a platform where women can exchange skills, learn from each other, and grow professionally without financial barriers. Users can teach their expertise, discover new skills, and connect with others through a skill-exchange system.

✨ Features

- 👩‍💻 Skill Exchange: Teach what you know and learn something new.
- 🔍 Smart Matching: Find users with complementary skills.
- 📅 Session Booking: Schedule learning sessions.
- 💬 Real-Time Chat: Connect with other learners and mentors.
- ⭐ Reviews & Ratings: Build trust through community feedback.
- 📊 Personal Dashboard: Manage skills, sessions, and learning progress.

🛠️ Tech Stack

- Frontend: React.js, Tailwind CSS
- Backend: Node.js, Express.js
- Database & Authentication: Supabase, PostgreSQL
- Real-Time Communication: Supabase Realtime
- Deployment: Vercel, Render
- Version Control: Git, GitHub

⚙️ How It Works

1. Create an account and add the skills you can teach.
2. Select the skills you want to learn.
3. Discover compatible skill-exchange partners.
4. Book sessions and connect with other women.
5. Share knowledge, gain skills, and grow together.

🌍 Impact

SkillSwap promotes accessible education, women’s empowerment, peer learning, and professional development by turning knowledge into a shared community resource.

🚀 Vision

A world where every woman can learn, teach, and grow through the power of shared skills.
